# Оно тебе надо

Учебный проект Яндекс Практикума: вёрстка главной страницы аукциона вещей, в которые никто не верил.

## Что внутри

- шапка с меню, логотипом и контактами (grid);
- обложка с фоновым изображением и оверлеем;
- секция «Лоты» с карточками (flexbox);
- секция «Об аукционе» (grid);
- подвал с адресом, меню и ссылками на соцсети.

## Технологии

- HTML5, семантические теги (`header`, `nav`, `main`, `section`, `article`, `address`, `footer`);
- CSS: flexbox, grid, позиционирование, БЭМ-именование классов;
- шрифт Raleway подключён локально.

## Как запустить

Откройте `index.html` в браузере. Сборка и сервер не нужны.
